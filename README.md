# 🛍️ Customer Analysis Project

## 📌 Overview

This project explores **customer shopping behavior** to uncover insights that help businesses improve sales and customer experience.
I performed **data cleaning**, **SQL analysis**, and built an **interactive Power BI dashboard** to visualize key trends.

---

## 🛠 Tools & Technologies

* **Python (Pandas)** – Data cleaning, feature engineering
* **SQL** – Querying customer segmentation, revenue trends, and top spenders
* **Power BI** – Dashboard design, KPIs, and storytelling

---

## 📂 Dataset

* **Rows:** \~99K
* **Columns:** Customer details, purchase categories, quantity, price, payment method, shopping mall, invoice date

---

## 📌 Dashboard Highlights

✅ **KPI Cards:** Total Revenue, Total Customers, Avg Spend/Customer, Total Orders
📊 **Visuals:**

* Revenue by Category & Shopping Mall
* Gender & Age Group Distribution
* Monthly Revenue Trends 
* Payment Method Breakdown


---

## 🎯 Skills Demonstrated

✔ Data Cleaning & Transformation
✔ SQL Joins, Aggregations, Group By
✔ KPI Design & Storytelling
✔ Power BI Dashboarding & Slicer Creation
✔ Business Insight Generation

---

## 🚀 How to Use

1. **Clone this repo**
2. Open the cleaned CSV (`customer_shopping_data_cleaned.csv`)
3. Run SQL queries or open the Power BI file to explore the dashboard
